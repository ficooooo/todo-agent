# 小明智能体 · 待办清单

基于 DeepSeek Function Calling 实现的中文待办清单智能体。用户可以直接用日常口语和「小明」对话来记录、查询、修改、完成或删除任务，数据实时落盘到本地 `data/tasks.json`，刷新页面或重启服务后依然保留。

## 已完成功能

基础对话管理之外，一并实现了题目列出的扩展方向：

- 通过自然中文完成待办的新增、查看、标记完成/撤回未完成、改名与删除，支持口语化表达（例如先记「洗衣服」，之后说「衣服洗好了」即可定位并更新状态）以及单句话批量操作。
- 支持截止日期（`YYYY-MM-DD`），能理解「今天」「明天」「这周日」等相对时间，并准确回答「今天有哪些任务到期？」（如有已逾期未完成的事项也会一并提示）。
- 支持任务的优先级（低 / 中 / 高）与预估工作量（小 / 中 / 大）设置、修改和清空。
- 支持创建和管理一层子任务，删除父任务时自动清理下属子任务。
- 改进清单展示：对话回复按「待处理」与「已完成」分组呈现；页面右侧新增了实时同步的待办面板，按逾期、今日到期、优先级排序突出待办事项，展开显示子任务完成进度，也支持直接在面板中勾选状态。
- 处理常见歧义与边界情况：重名或指代不清时先追问确认、空泛指令不盲目建任务、重复未完成事项主动提醒、清空全部任务前二次确认。

更多实现取舍和边界说明见 [SUBMIT.md](SUBMIT.md)，任务 HTTP 接口定义见 [server/openapi.yaml](server/openapi.yaml)。

## 运行方式

需要 Node.js `>= 24.12.0`。

1. 安装依赖并准备环境变量：

```sh
npm ci
cp .env.example .env
```

2. 打开 `.env`，填入有效的 `DEEPSEEK_API_KEY`（默认模型为 `deepseek-flash`，可按需修改 `DEEPSEEK_MODEL`）。本地 `.env` 已配置在 `.gitignore` 中，不会被提交到 Git。

3. 启动开发服务：

```sh
npm run dev
```

浏览器访问 <http://127.0.0.1:3000> 即可开始对话。若前端 TSX 有改动，执行 `npm run build` 重新打包静态资源；生产预览可执行 `npm start`。

## 验证方法

### 1. 页面交互验证

打开 <http://127.0.0.1:3000>，可以依次发送以下消息验证基础链路与扩展能力：

1. `帮我记一下买牛奶`
2. `再记一条取快递`
3. `我有哪些任务？`
4. `牛奶买好了`
5. `取快递这条删掉吧`
6. `再给我看看清单`
7. `帮我记一条今天交周报，高优先级，工作量大，下面拆两个子任务：汇总本周数据、列下周计划`
8. `今天有哪些任务到期？`

每轮对话结束后，右侧待办面板会同步更新；此时刷新浏览器页面或重启终端服务，聊天历史会清空，但右侧清单及后续对话查询依然能读到落盘的任务数据。

### 2. 自动化测试与静态检查

仓库包含针对 REST 接口、存储约束与智能体工具调用闭环的单元测试（使用临时目录与模拟客户端，无需消耗模型额度即可运行）：

```sh
npm test

npm run build
```
